## Arabic Clock 2.1.0 — test release

- New selected dark-felt launcher icon with large debossed Arabic-style numerals.
- Adaptive icon for round, squircle, and other launcher masks, plus density-specific fallback icons.
- Single-screen live widget preview and settings.
- Fully transparent Arabic clock widget with Amiri / Scheherazade numeral fonts, customizable color, size, width, and separator dots.

### Install
Download `Arabic-Clock-2.1.0.apk` below and open it on Android 8.0 or later.
Allow installation from that source when prompted. Add Arabic Clock using the app's
button or your launcher's widget picker.

**This APK is debug-signed for testing, not a production-signed Play Store release.**
If a previous test installation has a different signing key, uninstall it first
(this removes settings and placed widgets). A SHA-256 checksum is included.

Lock-screen widgets are available only on devices with compatible third-party
lock-screen widget support; this app cannot replace the system lock-screen clock.
The dark felt belongs to the app icon only. The clock widget remains transparent.

Build/lint and font/resource regression checks are automated. Physical-device and
launcher-specific testing has not been performed.
